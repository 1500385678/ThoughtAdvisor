## 主题摘要(按 id 排序)

### 01 · 毛泽东思想
- **关键词**:实事求是 / 群众路线 / 独立自主 / 矛盾论 / 实践论
- **摘要**:中国共产党集体智慧的结晶,核心方法论是实事求是,组织路线是群众路线,工作方针是独立自主。强调一切从实际出发,理论联系实际,在矛盾中把握主要方面。

### 02 · 邓小平理论
- **关键词**:解放思想 / 实事求是 / 发展是硬道理 / 黑猫白猫 / 摸着石头过河 / 不搞争论
- **摘要**:改革开放总设计师的思想体系,核心是解放思想实事求是,方法论是渐进式改革与摸着石头过河,价值准则是发展才是硬道理、实践是检验真理的唯一标准。

### 03 · 王阳明心学
- **关键词**:心即理 / 知行合一 / 致良知 / 四句教 / 事上磨
- **摘要**:明代心学集大成者,主张心外无物、心外无理,强调通过致良知与事上磨练实现知行合一,四句教为总纲。

### 04 · 曾国藩家书
- **关键词**:修身 / 四大支柱 / 至拙胜至巧 / 结硬寨打呆仗 / 敬胜怠义胜欲 / 用人之道
- **摘要**:晚清名臣家书语录,核心处世哲学是"天下之至拙,能胜天下之至巧",主张以拙诚胜巧诈,自我管理涵盖省身、读书、治家、用人四大支柱。

### 05 · 鲁迅思想
- **关键词**:立人 / 国民性批判 / 批判精神 / 独立思考 / 冷眼热心
- **摘要**:中国现代思想先驱,核心命题是"立人"——改造国民性以立人为先。主张以批判精神看透表象、以独立思考拒绝合群,做到"冷眼热心"。

### 06 · 墨子思想
- **关键词**:兼爱 / 非攻 / 尚贤 / 尚同 / 三表法 / 逻辑思维
- **摘要**:战国墨家学派代表,核心主张兼爱(无差别之爱)与非攻(反对侵略战争),政治上尚贤尚同,方法论上以"三表法"为中国早期逻辑思维的源头。

### 07 · 庄子思想
- **关键词**:逍遥游 / 齐物论 / 无为 / 庄周梦蝶 / 庖丁解牛
- **摘要**:道家代表人物,核心追求"逍遥"——精神上超越世俗束缚;认识论上"齐物"——万物相对平等;政治上主张"无为"。以寓言(梦蝶、庖丁解牛等)承载深刻哲思。

### 08 · 王夫之思想
- **关键词**:器体道用 / 日生日成 / 主动论 / 理势合一 / 通变 / 以史为鉴
- **摘要**:明末清初启蒙思想先驱,核心命题"器体道用"强调物质第一性,"日生日成"主张发展观,历史哲学上"理势合一"强调规律与趋势的统一。

### 09 · 近代启蒙思想
- **关键词**:天演论 / 新民说 / 少年中国说 / 中西对比 / 变亦变
- **摘要**:近代中国启蒙思想群谱,严复以《天演论》引入进化论与西方逻辑,梁启超以《新民说》《少年中国说》倡国民改造,核心命题是"变亦变,不变亦变"。

### 10 · 马克思主义哲学
- **关键词**:辩证唯物主义 / 历史唯物主义 / 对立统一 / 质量互变 / 否定之否定 / 社会存在决定社会意识
- **摘要**:由辩证唯物主义与历史唯物主义两大部分组成:前者讲唯物论与辩证法(对立统一、质量互变、否定之否定三大规律),后者讲社会存在决定社会意识,生产力与生产关系的矛盾推动社会进步。
